# 交付边界与后续计划

本仓库实现需求书的首个纵向开发切片，并非全P0完成。没有把待实现功能作为可用能力展示。

## 下一个增量：档案结构及权限

- 独立制作版本、人员、角色、计划/实际演职名单；多节目场次。
- 逻辑资料与不可变文件版本分离；分享固定版本。
- 部门、角色与对象范围权限；敏感票房字段访问策略。
- 元数据编辑、变更审计、归档流程与回收站。
- 接收人管理界面、验证码通道与审批策略。

## 后续P0增量：资料处理和上线保障

- tus续传、配额、完整性确认、病毒隔离与失败清理。
- FFmpeg转码/HLS、缩略图、Office转PDF；预览文件独立安全域。
- 文件网关Range、并发与限流；长流撤销时间实测。
- 已完成预览文件头匹配；继续完善完整内容解析及媒体格式白名单，目前仅可信样本试用。
- 票房台账、历史资料迁移、后台任务状态与运维界面。
- PostgreSQL与文件一致性备份、恢复演练、HTTPS、压测及发布回退。
- 不在Nginx路径日志中记录分享令牌；生产错误日志也要验证脱敏。

## P1

按需求书推进OCR、语音转写、标注剪辑、外部征集、统一登录、票务接入、冷热分层、分享配额及多节目分摊。

## P2

权限约束下的全文/语义检索、引用式问答、相似照片及年度汇编。模型接入前明确数据边界和评测集。
